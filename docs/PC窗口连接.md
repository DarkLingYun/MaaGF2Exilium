# PC 窗口连接

先启动《少女前线 2：追放》PC 客户端，再打开助手。游戏窗口必须同时满足类名 `UnityWndClass` 和少前 2 标题规则；资源管理器、助手自身和其他 Unity 游戏不会成为候选。

使用包含 MXU 自动窗口选择修复的完整安装包时，首次启动且只有一个合格游戏窗口，助手会自动选择“桌面端-前台”和“中文资源(PC端)”并连接。已有配置保留原来的控制器和资源选择；自动连接不会自动执行任务。

多个窗口无法通过历史记录唯一确定时，需要在连接面板选择目标。未找到窗口时，先启动游戏，再点击重新搜索。旧配置保存了错误窗口时，若当前只有一个合格窗口，重新搜索会修正选择并记录提示。

开始任务时仍会检查目标窗口。窗口关闭、句柄失效或目标不符合规则时，本次任务不会提交，界面会显示原因及重新搜索入口；选择正确窗口后可以重试。

上述自动选择和启动报错依赖 MXU 的配套修复。仅更新本项目资源能修正候选窗口过滤，不能升级旧助手程序的界面行为；完整功能需要安装包含修复后 MXU 的完整包。
